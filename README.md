## 🧑‍🚀 About Me

<img align="right" width="340" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="coding gif"/>

- 🚀 **Founder @ Babillion** — built [Tamir Yönet](https://github.com/dogancmn/tamiryonet-platform), a multi-tenant SaaS platform **actively used by 350+ businesses**

- 🔭 Currently building **[Zamok Live](https://github.com/dogancmn/zamok-live)** and **[Zamok Amplifier](https://github.com/dogancmn/zamok-amplifier)**
- 💬 Ask me about **multi-tenant SaaS architecture, offline-first PWAs, real-time systems (WebSocket), and payment/recurring billing integrations**
- 📫 Reach me at **dogangwd@gmail.com**
